# z-prd

Codex product workflow skills for turning one-sentence product ideas into reviewable product documentation, product design, UI prototype plans, and runnable prototypes.

## Skills

- `product-workflow`: end-to-end orchestrator with product document review gates.
- `requirements-analyst`: requirements analysis, PRD, user stories, acceptance criteria.
- `product-designer`: information architecture, page flow, product structure, MVP planning.
- `ui-prototyper`: interactive UI prototype planning and implementation guidance.

## Install

Copy the folders under `skills/` into your Codex skills directory, for example:

```text
C:\Users\<you>\.codex\skills
```

Then restart Codex or open a new thread so the skills can be discovered.
